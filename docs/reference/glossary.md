# Glossary

Project-specific terms and acronyms.

| Term | Meaning |
|---|---|
| Shipper | A person or business with cargo to be moved from point A to point B. |
| Fleet Manager | A person in charge of fleet operations in a logistics company. |
| PACRA | Patents and Companies Registration Agency, the Zambian agency for business registration, intellectual property registration and company records. |
| API | Application Programming Interface: rules that let software systems exchange data. |
| QR | Quick Response code, a two-dimensional barcode scanned to read stored information. |
| OCR | Optical Character Recognition: converting text in scans or images into machine-readable text. |
| MVP | Minimum Viable Product: the simplest working version with the main features. |
| PWA | Progressive Web App: a web application with app-like features such as installation and offline access. |
| RBAC | Role Based Access Control: access determined by a user's assigned role. |
| HGV | Heavy goods vehicle. The routing profile used for distance and duration. |
| OTP | One Time Password: a code that can be used once. |
| 2FA | Two Factor Authentication: two forms of verification before access. |
| SAST | Static Application Security Testing: examining source code for vulnerabilities without running it. |
| DAST | Dynamic Application Security Testing: testing a running application for vulnerabilities. |
| IDOR | Insecure Direct Object Reference: a user reaches another user's data by changing an identifier. |
| OWASP | Open Worldwide Application Security Project, a nonprofit providing security guidance and tools. |
| ZDPA-2021 | Zambia Data Protection Act, 2021. |
| ZECTA-2021 | Zambia Electronic Communications and Transactions Act, 2021. |
| Openrouteservice | The routing service used for distance and duration. |
| Gemini Files API | The API through which the Markdown reference files are uploaded for the Gemini model. Uploaded files expire. |
| Reference files | Markdown files, one per source document or dataset summary, given to the Gemini model as cost-estimation background. |
| SCMS | Supply Chain Management System: the USAID/PEPFAR delivery history behind the historical freight cost data. |
| ZMW | Currency code used in the reference files, for the Zambian kwacha. |
| Allocation, reservation | Both words describe a shipment being secured by a fleet company. The database table is `reservations`; the security requirements say allocation. |
| Reservation (status) | `accepted` when created, `cancelled` if called off. |
| Shipment match | A shipment and compatible truck pair holding route, cost estimate and the manager's decision. |
| WAF | Web Application Firewall: filters and sanitises web traffic before it reaches the application. |
| Vault | The secret manager that holds database, routing, email and application secrets. |
| CORS | Cross-Origin Resource Sharing: browser rules that control which sites may call the API. |
